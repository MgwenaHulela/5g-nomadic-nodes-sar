## Number check

Run `check_numbers.py`; the output is in `check_numbers.out`. **19 PASS, 4 flagged:**

1. **Adaptive-cap RTT upper bound: report says 109 ms, table shows 108 ms.** The report's 109 was the *downlink* ping for delta; the table reports uplink only. Use 108 ms (UL) in the paper.
2. **Adaptive-cap video latency: report says "0.30–0.42 s", table shows 0.30–1.08 s.** The report excluded delta, whose 1.08 s is its 10-packet FIFO at about 100 kb/s. The table includes delta. The paper must give 0.30–1.08 s or name delta's exception explicitly.
3. **Capped C all-4: 53.05 is a rounding boundary.** It prints as 53.1 in the summary. **Not a real mismatch.**
4. **Claim 3 wording.** The *raw* model's open−forest contrast at 120 s bins is +0.021 [+0.003, +0.038], significant (p = 0.017). It is n.s. at the cycle, 30 s and 60 s bases, and in the calibrated model at every base. Against a measured +0.117 at 120 s it is about 1/6 of the effect. **CLAIMS.md "indistinguishable from zero at every bin width" must become:** "not significant at the cycle, 30 s and 60 s bases; at 120 s, significant but about one sixth of the measured contrast". Table 3 uses the 60 s base.
