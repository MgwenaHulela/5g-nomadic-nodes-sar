# Claude Code project notes

A copy, taken 13 Nov 2026, of the notes Claude Code kept about this project on
the lab PC: how the stack behaves, its pitfalls, and results so far.
`MEMORY.md` indexes them.

To use them on another PC, copy them into Claude Code's memory folder for the
clone. That folder is named after the clone's full path, with `/` replaced by
`-`. For a clone at `/home/you/sar_sim`:

    mkdir -p ~/.claude/projects/-home-you-sar-sim/memory
    cp docs/claude_memory/*.md ~/.claude/projects/-home-you-sar-sim/memory/
    rm ~/.claude/projects/-home-you-sar-sim/memory/README.md

The notes describe the lab PC as it was; check any file, flag or path they
name before relying on it.
