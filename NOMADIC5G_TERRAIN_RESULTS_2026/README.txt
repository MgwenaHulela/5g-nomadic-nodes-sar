NOMADIC 5G / UAV-MOUNTED BASE STATION — GROUND-ROBOT CONNECTIVITY ACROSS TERRAINS
Results dataset (2026). SATNAC 2026 paper: "Where to Fly the Cell Tower:
Terrain-Dependent Positioning of a Nomadic 5G Node Serving Ground Robots in
Disaster Search-and-Rescue."

WHAT THIS IS
------------
Protocol-in-the-loop emulation (OpenAirInterface 5G SA + Open5GS core + Gazebo
physics, coupled by a real-time air-to-ground channel bridge). One UAV-mounted
gNB serves two ground-robot UEs (alpha = stronger link, bravo = weaker) across
five terrains. Each terrain is a 6-hour trial: phase 1 = STATIC gNB (0-3 h),
phase 2 = NOMADIC/roaming gNB (3-6 h). Both robots patrol throughout.

FILES (one row per measurement cycle, ~15-60 s apart)
-----------------------------------------------------
  open_field_results.csv   line-of-sight baseline        (733 rows)
  urban_results.csv        building NLoS                  (721 rows)
  forest_results.csv       foliage (Weissberger)         (482 rows)
  hills_results.csv        terrain diffraction           (974 rows)
  indoor_results.csv       outdoor-to-indoor penetration (low-gNB run)
  summary_stats.json       per-terrain/phase/robot aggregate metrics

KEY COLUMNS
-----------
  t_elapsed_s              mission time (s); phase 1 = <10800, phase 2 = >=10800
  phase                    1 = static gNB, 2 = nomadic gNB
  uav_x_m/uav_y_m/uav_z_m  gNB (UAV) position
  ax_m/ay_m , bx_m/by_m    robot alpha / bravo position
  a_/b_ d_slant_m          UAV-robot slant distance
  a_/b_ ploss_dB           injected air-to-ground path loss (attenuation)
  a_/b_ ss_rsrp_dBm, ss_sinr_dB   modem-measured RSRP / SINR
  a_/b_ tcp_tp_mbps        TCP goodput (sensor upload)
  a_/b_ udp_tp_mbps, udp_lost_pct, udp_jitter_ms   UDP video stream
  a_/b_ c2_rtt_ms, c2_loss_pct     command-and-control (base->robot, over air)
  a_/b_ dl_bler, ul_bits_per_sym   link-adaptation telemetry
  a_/b_ event, outage_s    RLF/reattach events + governor recovery time (s)

HEADLINE RESULT
---------------
The effect of gNB mobility on connectivity flips sign with terrain blockage:
  open field  roaming HELPS the weak UE   (C2 avail 56.5% -> 88.7%)
  urban       NEUTRAL                      (~96-98% both phases)
  hills       roaming HURTS mildly         (-10.6 pp)
  forest      roaming HURTS hard           (-22 pp; video loss > 70%)
  indoor      deep interior UNCOVERABLE    (12-18% C2)
